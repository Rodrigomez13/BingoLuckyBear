# LuckyBingoBear design references

Esta carpeta concentra las referencias visuales para el redisenio progresivo de LuckyBingoBear. No es codigo funcional: sirve como punto de control antes de tocar pantallas, componentes o flujos.

## Rama y alcance

- Rama base esperada: `feature/lbb-platform-wallet-games`.
- Rama de trabajo sugerida/actual: `refactor/lbb-responsive-design-system`.
- Objetivo de esta etapa: preparar referencias, auditar estado y evitar cambios grandes antes del redisenio.
- No guardar aca secretos, credenciales, comprobantes reales ni datos personales de usuarios.

## Criterios de uso

- Usar solo referencias alineadas con LuckyBingoBear: casino premium, negro, verde casino, dorado, brillos, oso mascota, bingo, Golden Bear, Viborita y Mazo LuckyBingoBear.
- No usar cartas genericas, poker ni barajas random como referencia para Truco.
- Antes de implementar cambios visuales, comparar contra los tokens de `TOKENS_VISUALES_LBB.md`.
- Mantener el catalogo visible enfocado en juegos disponibles.
- Toda UI final debe ser responsive y sin overflow horizontal.
